# Shadow Stage Demo Script

## Narration

| Step | Narration | Action | Duration |
|------|-----------|--------|----------|
| 1 | Shadow Stage: choreograph light and shadow with AI suggestions. Start with a preset shape and request ideas from Nemotron. | Wait for page load | ~2s |
| 2 | Choose a starting gesture. | Select "Paper flight" preset | ~1s |
| 3 | Describe what you want. Let's ask for a shape that drifts and returns. | Type brief in director's notes | ~2s |
| 4 | Request an AI suggestion from Nemotron on Nebius Token Factory. | Click "Request a suggestion" button | ~1s |
| 5 | Nemotron returns a physical construction suggestion tailored to your description. | Wait for model response | ~3s |
| 6 | Adopt the suggested construction and see it rendered on the stage. | Click adopt button | ~1.2s |
| 7 | The result is a choreographed shadow performance, with light and cutout paths optimized by Nemotron to match your target shapes and brief. | Show final result | ~1s |

## Total Duration
Approximately 2 minutes

## Key Points Demonstrated
- App loads and presents the studio interface
- User selects a starting silhouette preset (Paper flight)
- User provides a natural-language description of desired motion
- App sends request to Nemotron on Nebius Token Factory
- AI generates a physical construction proposal (light and cutout paths)
- User adopts the suggestion and sees it rendered in real-time
- Final shadow animation shows the choreography achieved with AI assistance
